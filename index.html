    🔑 Chaves de API

    Configure as integrações utilizadas nos módulos do sistema.

    🤖 OpenRouter / OpenCode Go IA Usado em: Extratos

    Para OpenCode Go, use o modelo opencode-go/deepseek-v4-flash e a chave obtida em opencode.ai/auth.

    🏢 CNPJá Opcional Usado em: Consulta CNPJ

    Sem chave: gratuito com limite de 5 consultas/min.
    Com chave: sem limite de taxa (plano pago em cnpja.com).

    ✍️ Autentique Assinatura Usado em: envio para assinatura

    A integração cria o documento na Autentique e envia por WhatsApp. Você pode cadastrar várias chaves, uma por linha, e o sistema revezará automaticamente entre elas.

    📨 Abrir módulo
    🔍 Tavily Search IA Contexto Usado em: classificador de despesa

    A busca web do Tavily enriquece a classificação de despesas com informações atualizadas de normas TCE-PR, MCASP e elementos de despesa. Sem chave: o classificador usa apenas o prompt interno. Com chave: resultados mais precisos.
